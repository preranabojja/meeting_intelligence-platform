# Meeting Intelligence Platform

An AI-powered meeting intelligence platform that transcribes meetings, generates summaries, extracts action items, and enables semantic search across meeting history.

## Features

- User authentication
- Audio upload
- Meeting transcription
- AI-generated summaries
- Action item extraction
- Semantic search (RAG)
- Team workspaces
- CI/CD pipeline

## Tech Stack

### Frontend
- Next.js
- TypeScript
- Tailwind CSS

### Backend
- Next.js API Routes
- Prisma ORM

### Database
- PostgreSQL

### AI
- OpenAI API
